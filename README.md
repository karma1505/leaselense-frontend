## 📜 Overview

**LeaseLense** is an intelligent document auditor designed to protect tenants from predatory rental agreements. Legal contracts are often long, complex, and filled with "silent killers"—clauses that look innocent but carry huge liability.

This **Frontend** provides a beautiful, accessible interface for users to upload their leases, visualize risks, and generate legal counter-offers in seconds.

### 🚩 The Problem
- **Complexity**: Rental agreements are written in dense legalese.
- **Vulnerability**: Tenants often blindly sign contracts, missing hidden clauses about deposit forfeiture, unexpected maintenance costs, or draconian eviction rules.
- **Cost**: Hiring a lawyer to review a ₹20k/month apartment lease isn't feasible.

### 💡 The Solution
LeaseLense acts as your **personal AI lawyer**. It scans your PDF, cross-references it with the **Model Tenancy Act (2021)** and **Maharashtra Rent Control Act**, and gives you a simple "Safety Score" out of 100.

## ✨ Key Features

| Feature | Description |
| :--- | :--- |
| **⚡ Instant Analysis** | Drag & drop your PDF and get a comprehensive audit in <30 seconds. |
| **💯 Health Score** | A clear **0-100 Safety Score** based on the severity of risks found. |

| **📱 Virality** | "Challenge Your Friends" feature to compare lease safety scores. |

## 🚀 Getting Started

Follow these steps to run the frontend locally:

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/leaselense-frontend.git
   cd leaselense-frontend
   ```

2. **Install Dependencies**
   ```bash
   pnpm install
   # or
   npm install
   ```

3. **Run the Development Server**
   ```bash
   pnpm next dev
   ```

4. **Open in Browser**
   Visit `http://localhost:3000` to see the app in action.
